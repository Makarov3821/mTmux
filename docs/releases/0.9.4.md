# 0.9.4：快捷发送与文档浏览优化

versionCode 45，目标标签 `v0.9.4`，正式版。standard 与 voice 延用既有 GitHub 签名流程。

## 改动

- 快捷回复点击即发送文字并回车，已有本地编辑草稿保留。连接或绑定 pane 改变时拒绝发送，不在恢复后自动重放。
- 语音转写继续进入可编辑卡片。默认点击“发送”同时提交并回车；语音版设置新增“编辑后直接发送”，关闭后使用“插入终端”，由用户手动回车。识别结束本身不会自动提交；手动新建的编辑草稿保持原交互。
- 汇总上一正式版以来的文档视口图片加载、缓存复用、单文件及缓存容量设置，以及 SVG 大小上限统一。快速滚动跳过途中图片，按最终浏览位置加载。
- 精简产品常驻提示，修复 Doctor 连接失败后的状态更新，整理中英文 README、使用与开发指南，统一 Release 正文来源。

实现与验证分别见[快捷发送](../design/direct-replies.md)、[定向回归](../testing/direct-replies.md)、[视口缓存验证](../testing/preview-viewport-cache.md)及[发布说明规范](../release-notes.md)。

## 发布前证据

- 快捷发送改动：app 两版 JVM 各 50 项、两版 Debug 与测试 APK 构建及 lint 通过；真实 Android WebView 与 SSH/tmux 定向回归 standard 6 项、voice 7 项通过，0 失败、0 跳过。
- 视口加载改动：两版 Android 各 12 项、真实 SSH/SFTP/PTY core 77 项、voice JVM 4 项，以及 Python、Node、桌面浏览器和两版 Debug/Release 校验通过。各轮失败和修正过程保留在原验证记录。
- 上述 Android 用例运行在专用 API 35 x86_64 / WebView 124 模拟器。语音录音用例不等于真实语音内容到提交的全过程验收，也不代表 ARM 真机、所有输入法或全部应用用例通过。
- 定向回归针对版本调整前相同产品源码；本次仅将版本更新为 0.9.4 / 45，发布检查与 GitHub 执行结果另存于 `.tools/diagnostics/release-094/`。

GitHub 发布前核对同一候选提交的 Android checks 与 Voice checks；标签触发 Release APK，生成 standard、voice 两个签名 APK 及对应 SHA-256 文件。不从 GitHub 导出签名私钥。
