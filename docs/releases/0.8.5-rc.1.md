# 0.8.5-rc.1：按住语音与标点模型对照预发行版

日期：2026-10-24，versionCode 33。预发行标签 `v0.8.5-rc.1`；不创建 `v0.8.5` 正式标签，Latest 保留正式版。

## 安装与模型选择

GitHub Release APK workflow 使用仓库既有签名密钥，构建并发布两份 **Release 配置、正式证书签名**的语音 APK：

- `mtmux-v0.8.5-rc.1-voice-ct.apk`：Whisper multilingual base q8_0 + CT-Transformer INT8 标点恢复，包体预计约 197 MB。
- `mtmux-v0.8.5-rc.1-voice-srf.apk`：同一 Whisper q8_0 + 2.24 MB SRF INT8 / 词表，包体预计约 137 MB。

最终大小与 SHA-256 以对应 Release 附件为准。两个包均为 `dev.mtmux`、0.8.5-rc.1 / code33，并包含 arm64-v8a / x86_64，可覆盖正式 0.8.4 / code32 保留配置，也可互相覆盖试用。无需卸载；本机早先的 `trial.apk` 使用测试证书，与本次 GitHub 构建不同。

设置可关闭“自动补充标点”以对照 Whisper 原文。CT 在五条固定样例的长句断句上更连贯，SRF 包体较小但出现过误断句；这不是总体准确率结论。q8 同样没有已验证的手机识别质量优势，需要真实录音试用。

## 行为变化

- 按住中央声波按钮准备麦克风，成功启动后绿色光晕与 60 秒剩余时长；最后 10 秒从绿到橙再到红。
- 松手转文字；上滑进入取消区，松手丢弃，移回继续。准备期间松手、退后台、切换目标或系统取消触摸会取消当前任务。
- Whisper 与标点顺序运行，标点 session 按需创建并关闭，失败回退原文；检测到的路径、URL、文件名、参数、引用代码、原标点与空格保留。结果只填入可编辑草稿，已有草稿保留追加/替换选择。
- 修正快捷键页码亮点的连续拖动与首尾衔接，保留四页循环和右滑下一页。

## 验证范围

发布前已在本地完成两种模型构建、app standard / voice 各 22 项单元测试、voice 模块每后端 13 项测试和四项下载完整性测试；两种 Debug lint 0 错误，模型摘要、权限/模型隔离、16 KiB ELF/ZIP 对齐与测试签名通过。Android 测试 APK 已编译，真实麦克风、手势、ARM 手机时延、内存与温升未计为已验收。

本次预发行流水线另外校验：标签等于 versionName、默认 CT 与轻量 SRF 的包名/版本相同、两者证书均与仓库固定的正式证书摘要相同、模型及词表精确匹配、包体小于 200 MB、APK 签名与 16 KiB 对齐。只有成功后才创建 pre-release，并显式禁止把它标记为 Latest；正式证书不会导出到本地。
