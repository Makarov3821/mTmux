# 0.8.5-rc.2：语音模型对照预发行版

2026-10-24，versionCode 34，标签 `v0.8.5-rc.2`。与 [rc.1](0.8.5-rc.1.md) 相比，只修正辅助 Voice checks 流程在构建 SRF 轻量包前漏下载模型和词表的问题，递增版本以保留已推送的 rc.1 标签。语音功能和模型参数不变。

发布两份 GitHub 原发布证书签名的 Release APK：

- `mtmux-v0.8.5-rc.2-voice-ct.apk`：q8 + CT-Transformer INT8，预计约 197 MB。
- `mtmux-v0.8.5-rc.2-voice-srf.apk`：q8 + SRF INT8 轻量模型，预计约 137 MB。

两份包都使用 `dev.mtmux`、0.8.5-rc.2 / code34，可覆盖 0.8.4 / code32 和 rc.1 / code33 保留配置，也可互相覆盖比较。只发布 pre-release，不创建 `v0.8.5` 正式标签，不更改正式版 Latest。

签名流水线对两个 APK 检查既有证书摘要、包名/版本、指定模型 SHA-256、权限/模型隔离及 16 KiB 对齐，通过后才发布附件和 SHA-256 文件。设备质量与性能仍需试用，详见 [模型记录](../testing/voice-models-20261023.md)。
