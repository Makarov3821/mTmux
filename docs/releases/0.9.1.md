# 0.9.1：输入连接恢复（Pre-release）

versionCode 37，标签 `v0.9.1`，显式标为预发行版，不替换正式 Latest v0.9.0。

- 修复终端直接输入的连接恢复缺口：返回时尚无窗口焦点，重建请求继续保留；视图与窗口同时获得焦点后重建，再次点击键盘也会修复缺失连接。
- 切换到其他编辑窗口时作废旧输入连接；返回后创建新连接。旧回调和晚到的 close 不会向新目标重放文字或破坏新连接。编辑卡片、SSH 和 tmux 的目标核验逻辑保留。
- 增加轻量 IME 生命周期日志，记录连接创建、作废、重建、焦点和首次提交/首次失效回调，不记录输入正文。完整逐批 SSH/渲染时延埋点尚未加入。
- 更新本地界面图集及 tmux Doctor / X-ASR 相关界面；截图产物停止跟踪并加入 Git 忽略，采集工具与复现说明继续保留。

standard / voice 均使用原发布证书、包名 dev.mtmux，可覆盖 0.9.0 保留配置。voice 保持同一 X-ASR 480ms INT8 模型。

旧开发安装上的两项定向回归按预期失败；修复版 7 项 Android 测试通过，包括真实 InputMethodManager 的重建与编辑窗口切换；两版各 41 项 JVM 单测、Debug 构建及 lint 通过。细节见 [输入连接恢复](../testing/terminal-ime-recovery.md)。用户手机和第三方输入法仍需复测，预发行用于收集切应用、熄屏和中文选词反馈。

本次更新 101 张本地截图（含 7 张 Doctor 状态），离线图集加载、筛选和放大检查通过。0.9.1 重建及版本/模型校验见 [本地检查](../evidence/0.9.1/local-checks.json)。截图产物不推送到仓库。
