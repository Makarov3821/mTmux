# 0.9.5：功能键顺序与版本信息

versionCode 46，正式标签 `v0.9.5`。

## 产品行为

- 终端快捷键第三组显示 F1–F6，第四组显示 F7–F12，保留循环翻页、分页指示与按键编码。
- 设置页增加“关于 mTmux”卡片，显示 `BuildConfig.VERSION_NAME` 和构建渠道。默认渠道为 GitHub；`-Pmtmux.distributionChannel=play` 将渠道配置为 Google Play，standard 与 voice 共用该配置。
- 项目和 Issue 入口使用无底色图标，保留 48dp 操作区域，点击后向系统浏览器发送对应 HTTPS 地址。
- 深浅色卡片与功能键图集使用独立采集入口；生成图片继续保存在 Git 忽略目录。操作说明见 [截图说明](../screenshots/README.md)。

## 构建与验证

本版本包含真实 OpenSSH/tmux 功能键验证，以及版本、渠道和系统浏览器入口的设备验证。具体执行范围见 [0.9.5 验证记录](../testing/release-0.9.5.md)。

GitHub Release APK workflow 使用现有签名配置构建 standard 与 voice。发布时核对同一候选提交的 Android checks、Voice checks 与 Release APK，验证两个 APK、两个 SHA-256 文件、版本及证书。
