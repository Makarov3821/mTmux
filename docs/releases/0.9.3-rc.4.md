# 0.9.3-rc.4：远端文件预览与首页下拉刷新（Pre-release）

versionCode 42，标签 `v0.9.3-rc.4`，自动标为预发行，不替换正式 Latest。在 [0.9.3-rc.3](0.9.3-rc.3.md) 基础上：

- 终端链接可打开内置文件预览：Markdown 渲染表格、代码与图片，静态 HTML 关闭页面脚本，独立图片支持缩放/拖动；外部 HTTP(S) 链接交系统浏览器。
- 复用当前 SSH 的独立 SFTP 通道，不新增常驻 SSH；关闭后清理临时缓存。相对路径采用已确认的 pane/项目目录，支持远端绝对路径和 `file:///`、localhost、当前主机的 file URI。绝对路径不会放宽既有目录范围；需要引用其他目录时可手动调整基准目录。
- 预览采用当前主题的可关闭浮窗，与终端输入、语音等操作互斥；限制文本、图片、像素及总缓存大小，不访问手机本地文件、不自动加载互联网资源。服务器需提供 SFTP；动态 HTML、SVG、PDF、Mermaid、CSS file URI 和 srcset 不在本轮新增支持范围。
- 修复终端快捷键分页指示：左滑亮点向右，右滑向左，首尾循环；保留闲置 5 秒隐藏。
- 首页列表到顶后下拉，达到阈值松手刷新，配套主题图标与进度动画；只刷新未分组与已展开分组服务器，跳过 5 分钟间隔，保留连接复用、并发限制和展开状态。
