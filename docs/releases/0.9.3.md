# 0.9.3：远端文件预览与界面更新

versionCode 44，标签 `v0.9.3`，正式版。standard / voice 使用既有发布证书，可覆盖旧版本保留配置，同一设备一次安装一种。

- 汇总 0.9.1～0.9.3 预发行中的输入法连接恢复、主页与终端界面更新，以及快捷键分页指示修复。
- 首页到顶后下拉刷新，保留主题动画、折叠分组限制、连接复用与并发限制；结果由服务器卡片显示。
- 终端可点击远端 Markdown、静态 HTML 和图片，外部网页交系统浏览器。修复中文宽字符、显式换行、括号包裹导致的路径漏识别和网址截断。
- 预览中直接编辑完整文件路径，输入框为两行高；加载失败自动展开，成功后通过右上角按钮展开/收起。删除基准目录说明与重复路径行。
- PNG、JPG/JPEG、WebP 与 SVG 图片预览；SVG 支持独立浏览、缩放及文档内嵌，复用现有 WebView，无新增依赖。SVG 使用图像模式，不运行脚本、不加载外部引用。
- 预览复用当前 SSH 的独立 SFTP 通道，保留目录 realpath、大小、像素与缓存限制；关闭后清理临时文件。不为文件浏览新增常驻 SSH。

## 验证

发布候选的完整自动化测试结果记录在 [0.9.3 测试记录](../testing/release-0.9.3.md)。只有全部必需检查通过后才推送正式标签。API 35 x86_64 模拟器验证不等于 ARM 真机或所有厂商输入法验收；文档图集生成器不计入功能回归。

静态 HTML 不运行页面脚本；不支持动态网页、PDF、CDXML 等格式。相对路径基于 pane 目录/HOME 候选，不能任意推断 Agent 在其他项目中的工作目录；完整路径可由用户直接修正。
