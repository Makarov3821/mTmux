# 0.8.4：无边终端底栏与粘滞组合键

日期：2026-10-22，versionCode 32。standard / voice 保持同一应用 ID `dev.mtmux`、版本号及既有签名配置。

## 行为变化

- 终端底栏去掉常驻键帽底色、输入框描边和分隔线，发送按钮合入输入框右侧；保留 48 dp 顶栏、156 dp 底栏与既有终端网格预算。
- 移除底栏“收起键盘”。standard 的工具、快捷回复各占半栏并居中；voice 中央使用 52 dp 圆形语音按钮，工具、快捷回复各自在两侧剩余空间内居中。语音按钮采用提供的声波矢量图标，圆底和图标跟随主题及明暗模式。
- 快捷键新增第四页 Ctrl / Shift / Alt / ← / → / ⌫。修饰键点击后高亮，可叠加，再次点击可取消；下一次软键盘或实体按键使用组合并自动释放，原有草稿保持不变。例如 Ctrl → a 为 Ctrl+A，Ctrl → e 为 Ctrl+E，Shift → i 为 Vim 的大写 I。
- 快捷键栏双向首尾循环：右滑进入下一页，第四页继续右滑回到第一页；第一页左滑进入第四页。翻页保留等待中的组合键。
- 组合键沿用当前 SSH 与目标 pane 的输入路径。切换连接、回复目标、进入其他操作面板或退后台清理等待；旧输入连接的组词/提交回调不会重放已消费的按键。

## 验证与兼容性

- app 单元测试 standard / voice 各 15 项，包含新增的 7 项按键编码、状态消费、循环页码与旧 IME 回调隔离测试；本地两个 debug APK、两种 Android 测试 APK 构建及两种 debug lint 已通过。
- 发版前本地复核：core 31 项通过、16 项依赖 SSH fixture 的测试跳过；voice 4 项及上述两种 app 单元测试通过。两个 0.8.4 / code32 的未签名 Release APK 构建、Release lint（均 0 错误）、权限与模型分离、16 KiB 对齐检查通过；debug 专用测试 Activity 不进入 Release manifest。正式签名由 GitHub 执行。
- 独立 tmux socket、空配置下实际检查 Ctrl+A / Ctrl+E 的 Readline 行首行尾编辑与 Vim 的 Shift+I 行首插入。
- 粘滞键实现阶段已运行 standard 的两个独立 Android 输入组件用例。后续底栏布局、圆形语音按钮及居中调整完成构建检查，模拟器系统服务重启/安装超时阻止了新的设备截图和完整界面复测；未计为完整 Android 真机验收。
- 采用传统终端编码。Ctrl+A、Ctrl+E、Shift+I 等可直接使用；Ctrl+Shift+C 与 Ctrl+C 等组合在传统协议中可能无法区分，不新增 Kitty / CSI-u / modifyOtherKeys 协商。具体快捷键含义仍由远端程序决定。
- [输入与底栏验证记录](../testing/terminal-keyboard.md)、最新布局效果图（历史截图已清理）、[HTML 预览](../design/mockups/terminal-dock-v3.html)。效果图为按当前代码绘制的设计示意，非 APK 实机截图；旧组件截图明确标为底栏调整前。

## 发布

推送 `v0.8.4` 标签后，现有 Release APK workflow 运行单元测试、构建正式签名 standard / voice APK，并验证同证书、包名、版本、语音权限/模型分离及 16 KiB 对齐，随后发布 GitHub Release 和校验文件。最终构建结果以对应 Actions 和 Release 附件为准。
