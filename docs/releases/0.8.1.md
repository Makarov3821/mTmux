# 0.8.1：任务重连、连接性能和分阶段日志

日期：2026-10-18，versionCode 29。保留 standard / voice 双版本，同一 applicationId `dev.mtmux`；GitHub 签名打包沿用仓库已配置的证书。CI 与签名打包结果以对应 Actions 运行记录为准。

## 修复与优化

- 重连优先使用本次选中的服务器和原 pane。首次连接失败、凭据读取失败或连续重试均不会回到上一个成功任务；最近成功历史仍只在成功进入后更新。
- 进入 tmux 合并目标身份校验、名称读取和会话鼠标设置；准备请求、PTY attach、接入后核对共三个 SSH 通道。目标结束或重建仍拒绝重连，不自动发送旧草稿。
- 首页先读取带完整身份的任务列表，再补画面状态。每批最多八个 pane，同一服务器最多两个批次并行，保持输出上限及最终列表顺序。
- 前台最多保留两条空闲 SSH 连接 20 秒，供后续刷新或进入终端复用；配置、凭据或任一级主机信任变化时不复用，过期或退后台关闭。
- 取消时直接中止 DNS 等待和已登记的 socket，旧尝试单独记录取消结果；不会重新激活已取消的 client。

## 日志 v2

导出头包含 `build=connection-perf-v2`。DNS、TCP、服务器 banner、密钥交换、认证、SSH 就绪、tmux 列表/准备/状态、通道打开/命令等待、终端打开和首批字节分别记录耗时。

日志包含当前进程唯一的尝试和操作编号、父操作、跳板序号、结果、退出码及字节数，不保存原始 SSH 日志、主机地址、凭据、命令或终端正文。原始导出可存放在 Git 忽略的根目录 `debug-log/`。

字段边界、跳板计时说明与手机复测步骤见 [连接性能与日志 v2](../testing/connection-performance.md)。

## 本地验证

- 29 个 core 单元测试、9 个真实 loopback OpenSSH 集成用例、3 个 app 单元测试通过。
- standard / voice debug 构建与 lint 通过；standard Android 测试源码通过编译，两个 APK 均验证签名及 v2 日志标记。
- 10 pane 状态读取的两次本机结果为 147、157 ms，三个命令通道；初始实现单次 307 ms，四个通道。均不含 SSH 握手，不代表手机网络的固定提速比例。
- 无 banner 对端取消用例要求两秒内退出，实测不足一毫秒；连接池容量、到期和后台清理、两级跳板、特殊名称、重建目标拒绝、列表先回调及两批并行均有覆盖。

本地完整 SSH 套件中的六个交互 PTY 用例与改动前同样失败，没有将其计为本轮通过；GitHub CI 会执行完整套件。当前无连接设备或可用 KVM，本轮新增 UI 用例尚未在设备执行。voice 的 ARM 真机质量和性能门槛沿用 0.8.0，未声称在本轮完成。
