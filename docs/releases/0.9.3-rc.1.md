# 0.9.3-rc.1：0.9.2 真机反馈修复（Pre-release）

versionCode 39，标签 `v0.9.3-rc.1`，带 `-rc` 后缀自动标为预发行，不替换正式 Latest v0.9.0。

## 修复

- 首页顶部状态总览：刷新后不再变少或消失。原因是总览判断过期用的时间每分钟才更新，新刷新的状态被当成异常算作灰色。
- 首页任务行右侧的 `>` 右对齐；服务器标题与下方状态点左对齐。
- 终端铺满宽度：Android 滚动条不占宽度时，不再预留 15px，右侧最多空出不到一个字符。
- 终端快捷键与工具栏之间加宽 6dp（约 1mm）；翻页指示只亮当前页的点。
- 设置分段选择（如英文的 Very many 换行时）：其他选项保持垂直居中。

## 验证

Android 15 模拟器带临时 SSH/tmux 环境逐类运行：voice 75/75；standard 68/69。失败的 `TmuxDoctorUiTest#offlineDiagnosis…` 在未改动的代码上同样失败，原因未查。新增 3 项测试，把对应修复改回后均会失败；翻页点与间距用截图核对。详见 [界面改版测试记录](../testing/ui-redesign-test-record.md)。
