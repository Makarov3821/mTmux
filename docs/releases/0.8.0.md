# 0.8.0-dev：standard / voice 双版本与离线语音输入

日期：2026-10-17，versionCode 28。状态：功能、构建和模拟器回归完成；ARM 真机质量/性能验收待执行，非稳定版。

## 发布形态

| flavor | applicationId / 签名 / 版本 | release 大小（本地） | 权限与内容 |
| --- | --- | ---: | --- |
| standard | `dev.mtmux` / 相同 / 0.8.0-dev (28) | 约 12.1 MB | 无 `RECORD_AUDIO`，无 Whisper 模型/native，四按钮底栏 |
| voice | `dev.mtmux` / 相同 / 0.8.0-dev (28) | 约 74.5 MB | `RECORD_AUDIO`，base q5_1，arm64-v8a+x86_64，五按钮底栏 |

两者不能同时安装，但可同版本覆盖切换并保留应用私有数据。切回 standard 后启动会异步删除 voice 提取到 `noBackupFilesDir/voice/` 的模型，释放约 60 MB；其他配置/凭据保留。release workflow 同时发布 `*-standard.apk`、`*-voice.apk` 及各自 checksum，并要求两个 APK 与仓库固定证书一致。

## 用户交互

voice 终端底栏顺序：

`工具 / 收起键盘 / 麦克风 / 快捷回复 / 发送回车`

1. 只有已连接且没有发送中的终端可点击麦克风；第一次点击才请求录音权限。
2. 麦克风准备和 `AudioRecord.start/stop` 均不在主线程。录音使用 16 kHz mono PCM16，有界内存，最长 60 秒；退后台、关闭页面、目标变化或取消时停止。
3. 停止后用内置 whisper.cpp 1.9.5 multilingual base q5_1 本机转写。音频/转写不落盘、不上传、不进入日志。
4. 空草稿直接填入；已有草稿显示转写并要求“追加 / 替换 / 取消”。所有路径只修改 Compose 草稿，绝不调用发送；用户仍须编辑并点击发送。
5. 录音开始时绑定连接 token 与 pane 草稿 key；推理完成和最终追加/替换点击都在主线程重新核对当前身份。变化后拒绝写入。
6. PCM 纯静音/低于保守 -60 dBFS 门槛、空文本或 Whisper no-speech probability ≥0.8 时不修改草稿。

## 语言设置

设置仅在 voice flavor 显示“自动检测语言”，默认关闭：

- 关闭：简体中文界面传 `zh`；English 及无资源回退界面传 `en`。这避免 V0 中 auto 近翻倍的额外耗时。
- 开启：传 `auto`，由 Whisper 检测；适合语音语言与界面不一致时。

该设置保存在本机，不记录具体语言到诊断日志。

## 验证

- Android 15 x86_64 模拟器：standard 完整 36 项、voice 完整 41 项，均 0 失败/跳过；voice 比 standard 多 bundled model、取消、AudioRecord 和实际语音 UI 路径。
- JVM：voice 语言/静音门槛及 app 草稿 offer/final commit；覆盖 `auto`、界面语言、空/已有草稿、连接/pane 变化和最终追加/替换。
- 产品 instrumentation：固定 JFK WAV 从 voice test APK 输入，验证 bundled base 提取+SHA、英文转写、取消发生在 native 前和推理中；`AudioRecord` 可用时读取有界 PCM，不可用时验证失败不泄漏/卡死。
- UI instrumentation：standard 不出现语音设置/按钮；voice 开关默认关闭且持久化，按钮位于收起键盘与快捷回复之间；实际录音→停止→转写/干净错误不进入 `sendDraft`。
- APK：standard/voice 权限和 payload 隔离、相同 package/version/cert；voice 低于 100 MiB、只含 arm64-v8a/x86_64；模型 SHA 和 16 KiB 对齐通过。
- 覆盖安装：standard → voice → standard 同 versionCode 成功并保留 sentinel 私有数据；standard 启动删除 voice 模型目录。
- 本地一次性密钥模拟：standard 12,114,355 bytes，voice 74,492,953 bytes，同证书/包名/版本。

## 限制

- 当前只有 Android 15 x86_64 模拟器完成自动化模型转写；这证明链路，不代表 ARM 手机延迟、内存、温升、耗电或中文质量。
- `base q5_1` 在 V0 x86 模拟器显式英文 RTF 约 1.06；ARM 真机可能快或慢。最长 60 秒只是内存边界，不是低端机体验承诺。
- 无 Google 服务不影响本地 Whisper；但麦克风实现、蓝牙/来电抢占、厂商后台策略仍须真机验证。
- voice 安装包内模型约 60 MB，首次使用还会在私有 no-backup 目录提取一份，因此设备实际存储占用高于 APK 下载大小。
