# 0.8.5：终端直接输入与服务器管理

2026-10-28，versionCode 35，正式标签 `v0.8.5`。

## 变化

- 终端移除常驻本地回复框。点终端或顶部键盘按钮直接输入；中文组合过程本地预览，确认后发送，Ctrl / Shift / Alt 粘滞组合键保留。
- 语音结果、快捷回复和长文本使用临时编辑卡片。可修改、追加录音或关闭保留；确认“插入终端”后收起卡片，不自动回车。远端已有内容继续由远端编辑器管理。
- 输入队列合并等待期间的同目标字节，保持目标校验、顺序和粘贴确认边界；未消除孤立按键的 SSH exec 和回显 RTT。连续退格分别处理本地组词和重复按键，不要求 KEY_UP 后才接受下一次。
- 每台服务器可创建独立命名 tmux 会话，远端精确检查重名并原子创建，成功后用同一 SSH 链直接进入。
- 新服务器保存时主动连接并在握手中确认各级指纹，认证成功才保存。失败可重试、修改或 Save anyway；强制保存不提交临时指纹、不立即再连接。已保存主机密钥变化仍拒绝，原有验证入口保留。
- 从终端返回首页，仅对应且不属于折叠分组的服务器跳过探测间隔。其他服务器保持正常策略，自动间隔从 30 分钟缩短为 5 分钟；状态颜色的本地过期时间仍为 30 分钟。
- 保留 rc 版本的按住录音、60 秒光晕倒计时、最后 10 秒变色、上滑取消和可关闭的离线标点恢复。

## APK 与升级

正式 Release 由 GitHub Actions 使用既有发布证书生成：

- `mtmux-v0.8.5-standard.apk`：不带录音权限、语音模型和语音运行库。
- `mtmux-v0.8.5-voice.apk`：Whisper multilingual base q8_0 + CT-Transformer INT8，arm64-v8a / x86_64，本机录音、识别和标点恢复。

两份包使用相同包名、版本和签名，一次安装一种；可覆盖 0.8.4 / code32、rc.1 / code33、rc.2 / code34 保留本机配置。签名、模型 SHA-256、权限隔离、体积及 16 KiB 对齐通过后才发布 APK 和校验文件。

本轮主应用继续使用 q8 + CT。Paraformer / X-ASR 等候选的比较工具位于独立 `test-audio/`，不打入 mTmux；SRF 保守标点改动用于可选 SRF 构建，不改变正式 voice 的 CT 模型。

## 验证与边界

- 服务器管理阶段：完整 loopback SSH/core 61 项通过，包括等待指纹后继续同一次握手、错误认证分类、特殊会话名与并发重名拒绝。
- 终端输入阶段：standard / voice 各 40 项单测、两版构建及 lint 通过；Web 5 项单测和浏览器协议/组词覆盖层检查通过。
- Android 输入连接与相关界面用例完成编译。软件模拟器系统服务不稳定，未完成本轮设备执行；不代表实际手机输入法已验收。
- 用户反馈的“首次长按退格只处理最后一个标点”尚未复现，根因未确认；本次输入路径处理需要用实际输入法复测。
