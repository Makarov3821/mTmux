# 0.9.0：X-ASR 语音输入与 tmux Doctor

2026-10-30，versionCode 36，正式标签 `v0.9.0`。

## 变化

- voice 使用 Audio Lab 选定的同一 X-ASR 480ms INT8 中英模型，直接生成标点和大小写，移除自动识别语言和独立补标点开关。按住说话、60 秒倒计时、最后十秒变色、上滑取消、可编辑卡片与确认插入保留，不自动发送回车。
- 删除主应用 Whisper/ggml 引擎、CT/SRF 后处理、旧模型和独立 ONNX Java 运行库；删除旧主工程语音 benchmark 与对照发布流程。升级在后台清理已解压旧模型与旧偏好，独立 `test-audio/` 历史对照继续保留。
- 新增可选 tmux Doctor：验证保存后可选择诊断，服务器菜单也可重复运行，逐项显示安装情况、版本、鼠标滚动、历史与使用环境。tmux 3.2a 为兼容基线，更早版本在版本行提示。
- 已知未安装或不可用的 tmux 暂时限制创建会话，诊断状态五分钟后过期，配置变更也会失效；普通 SSH 保留。符合条件的首次使用者可预览并创建最小配置，支持保留备份的撤销，不自动覆盖现有配置。
- 点击终端或键盘按钮时，输入焦点和键盘高度变化立即参与可见位置调整，减少 Agent 输入区被键盘遮挡的问题，不改变终端逻辑网格。
- 暂停上一轮自定义退格实验，组合区恢复 Android 默认删除，浮动草稿恢复普通字符串状态，普通终端退格转发保留，继续收集实际输入法反馈。

## APK 与升级

GitHub Actions 使用既有发布证书生成：

- `mtmux-v0.9.0-standard.apk`：无录音权限、语音模型和语音运行库。
- `mtmux-v0.9.0-voice.apk`：离线 X-ASR 480ms INT8，包含 arm64-v8a / x86_64，预计约 193 MB，最终大小见正式附件。

两种 APK 的包名均为 `dev.mtmux`，versionCode 36，使用同一证书；一次安装一种，可覆盖旧正式版保留服务器、凭据和主机信任记录。已解压的旧语音模型会清理；首次使用 X-ASR 需在私有无备份目录安装约 169 MB 模型文件，安装空间还包含 APK 与运行库。标准版会清除私有语音模型目录。

模型部署文件与词表合计 169,227,953 bytes / 161.39 MiB。INT8 方案的 decoder 仍为 FP32；文件与运行时 SHA-256 固定在 `voice/model.lock.json` / `voice/runtime.lock.json`。正式发布前校验两包的证书、包名、版本、权限隔离、模型/运行库哈希、旧资源与旧类清理、体积及 16 KiB ZIP 对齐。

## 验证范围

0.9.0 发布前已重新构建两种 Release、运行 core / voice / 两种 app 单测及两种 Release lint，均通过；core 中 23 项显式 opt-in 用例按预期跳过。版本与模型/运行库校验通过，本地 unsigned 包为 standard 12,394,375 bytes、voice 193,095,601 bytes。见 [发布前检查](../evidence/0.9.0/local-checks.json)。

- 迁移阶段：主应用两种 flavor 的 Debug / Release、voice 测试 APK 与 lint 通过；JVM 单测 80 项、Python 资源测试 7 项通过。独立 Audio Lab 回归 25 项通过。
- Android 15 软件 x86_64 模拟器：旧模型/偏好清理、转写前取消、转写中取消、录音资源释放通过；单线程固定中文音频完整解码通过。四线程中文轮与后续英文轮因软件模拟器耗时较长主动终止，不能计作完整通过。
- 桌面 sherpa-onnx 1.13.8 对固定中英文音频的解码均通过；以上不代表 ARM64 真机的时延、准确率、内存或温升验收。
- tmux Doctor 阶段：core 72 项中 49 执行通过、23 需显式开启的用例跳过；两个 SSH 集成用例、Android 交互与复用链路、独立 tmux 3.2a 回归通过。细项和边界见 [Doctor 验证记录](../testing/tmux-doctor.md)。
- 实际手机输入法、长语音、中英混说、英文端侧完整转写仍需安装后继续试用。

迁移证据：[X-ASR](../testing/voice-xasr.md)；历史输入改动：[直接输入](../testing/terminal-direct-input.md)。0.9.0 构建、CI 及正式附件哈希以 GitHub Actions、Release 附件和各自 `.sha256` 为准。本机 unsigned / debug APK 不替代正式签名附件。
