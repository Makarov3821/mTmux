# 0.8.3：界面改版与远端滚动倍率

日期：2026-10-20，versionCode 31。standard / voice 保持同一应用 ID `dev.mtmux` 与版本号，沿用既有签名配置。

## 行为变化

- 首页服务器使用圆角卡片，任务与多 pane 采用分层背景、状态点、缩进引导线及上次使用标签；刷新进度和错误在卡片内展示。
- 设置按外观/语言、SSH 连接、终端/输入、隐私/语音和诊断分组；编辑页按目标信息、认证和高级选项分区，跳板操作适应窄屏。
- Tokyo Night、Catppuccin、Emerald、Zinc、Nord、Paper 六套主题均补齐浅深配色，支持跟随系统。既有安装首次迁移保持 Emerald，新安装默认 Tokyo Night；原生界面与终端颜色同步，切换不重建终端或 SSH。
- 终端统一顶栏、键帽、草稿输入框及发送操作；保留 48 dp 顶栏、156 dp 底栏与既有键盘裁剪机制。工具、快捷回复、复制、指纹和私钥导入等面板统一视觉，保留敏感页面保护、发送预览与原生选区手柄。
- voice 使用分阶段录音/转写底部面板，显示真实录音时长和进度；结果只填草稿，已有草稿仍明确选择追加或替换。
- 远端滚动倍率提供 1×～10× 十档，默认 1×，设置与终端工具即时同步并持久保存；旧浮点偏好迁移到最近的有效整数档。同距离滑动按倍率发送更多真实鼠标滚轮事件，不修改 tmux 配置，不新增握手、保活或状态轮询。每帧与待发队列均有限制，松手、反向、取消、断线或切换目标会清理未发事件。

## 验证与限制

- standard / voice 各 8 项 app 单元测试通过；两个 debug APK 构建、lint、验签及 standard Android 测试 APK、voice Android 测试源码编译通过。
- Web Node 测试 5 项通过；Chromium 加载实际打包终端的回归通过。同一慢滑在 1×、5×、10× 分别产生 3、15、30 个滚轮事件，覆盖方向、停止清理、目标切换、鼠标协议及主题切换保持网格/文字。
- Android 35 ATD、360 dp 实际截图已检查首页、多 pane 和深色设置；完整原生 UI 测试受模拟器 WebView 124 SIGTRAP 中断，未计为通过。ARM 真机、大字体/412 dp、voice 录音转写和远端 TUI 手感仍需复测。
