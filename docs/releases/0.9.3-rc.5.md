# 0.9.3-rc.5：刷新提示与终端链接点击修复（Pre-release）

versionCode 43，标签 `v0.9.3-rc.5`，自动标为预发行，不替换正式 Latest。在 [0.9.3-rc.4](0.9.3-rc.4.md) 基础上：

- 首页下拉刷新结束后不再显示全局红色提示，包括没有可刷新目标的情况。保留刷新图标、动画、折叠分组限制及服务器卡片的成功、失败、指纹等状态。
- 修复中文宽字符自动折行留下的空占位被误当成路径空格，导致文件路径只识别后半段的问题。
- 兼容 Agent/TUI 在终端右边界附近显式换行、添加续行缩进的文件路径和 HTTPS 网址，拼接完整内容后再识别；可点击续行部分。相邻独立链接和空行保持边界，不对整段输出去空白拼接。
- 链接点击由本地预览/浏览器入口消费，不同时发送远端鼠标点击或请求键盘。不需要修改服务器 tmux 配置；拖动、长按及点击期间内容变化仍按原规则处理。
