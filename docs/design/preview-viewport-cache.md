# 文件预览：视口加载与容量缓存

2026-11-02，基于 `d0221a8` 的工作区开发改动，尚未发布。替换 0.9.3 的累计资源个数限制，沿用现有 SSH、主题、浮窗与路径校验。

## 用户设置

- 图片或文本单文件上限：默认 **10 MiB**，适用于 Markdown、HTML、CSS、SVG、PNG、JPEG、WebP。SVG 不再按旧的 2 MiB 文本门槛处理。
- 文档预览缓存上限：默认 **50 MiB**，按每个预览浮窗计算；在同一浮窗点击关联文件和返回时共用，关闭后清理。
- 设置位于独立的“文件预览”卡片，使用现有主题、SettingRow 和 AppDialog。单文件可设 1～100 MiB，缓存可设 1～1024 MiB，缓存不能小于单文件上限；修改在下次打开预览时生效。
- 不再累计限制为 32 个资源，也不保留原先固定 100 MiB 的全局门槛。缓存满时淘汰最久未访问的项，继续允许浏览和重新下载。
- 单文件超限显示简短错误，容量可在设置中修改；内嵌图片失败可点击重试。

## 加载与快速滚动

1. 主文档文本完整读取并渲染；静态 CSS 完整读取以形成正确布局。图片在 DOM 清理阶段去掉实际 src，防止浏览器先行拉取离屏文件。
2. 内嵌 PNG/JPEG/WebP/SVG 与普通 CSS 背景图只在当前可见区域、上方一屏、下方一屏范围内进入队列。折叠或零面积的内容不下载，展开后重新判断。
3. IntersectionObserver 维护附近元素集合，滚动时仅计算附近及刚离屏元素的位置；布局、折叠、窗口大小和缩放变化都会更新判断。
4. 当前屏幕优先，然后按滚动方向预取相邻区域。一次传输一个图片，避免远处预取占满通道；新的当前屏幕图片可抢占尚未完成的预取。
5. 滚动速度超过 1.5 屏/秒，或单次位置变化超过 0.8 屏时，取消过时下载并暂停新下载；最后一次快速滚动后约 180 ms 恢复。慢速连续滚动允许继续加载，不强制等到抬手。
6. 快速跳转文档中部、末尾或锚点时，旧队列直接失效；停稳后从新位置重新排队。带单调序号的原生视口计划拒绝迟到的旧请求，取消不仅作用于前端队列，也中止对应 SFTP 传输。
7. 离屏图片释放浏览器 Blob 与解码引用，文件仍留在私有磁盘缓存。回到原位置先读取缓存，命中不发 SFTP 文件请求。
8. 未提供尺寸的图片先显示占位，加载后保留尺寸，便于回滚和后续布局判断。大分辨率位图内联采样至最多约 2 MP；原文件保留，点开独立图片浏览使用原有缩放和更高采样预算。

## 缓存与连接

- LRU 按真实文件字节容量管理。SFTP 返回大小后先为新文件腾出缓存空间，成功下载后入缓存；取消或失败的临时文件不保留。
- 缓存文件可能被系统清理，缺失视为未命中并修正容量记录。已经打开的响应流可以继续读取，后续缓存淘汰不打断它。
- 资源 SFTP 通道连续复用；取消时仅关闭当前资源通道，下一个任务仍使用同一条已认证 SSH 链创建 SFTP 通道，不新建 SSH 握手、不影响终端。
- 关闭浮窗会取消剩余资源请求、释放通道、清理缓存；预览文本、路径和文件内容不进入诊断日志。
- UI 状态在 Main.immediate 更新；会话所有权与重试代次使用原子持有，不由 IO 修改 Compose 状态。WebView 销毁后忽略迟到的失败/资源阻止回调。

## 隔离与静态 HTML

HTML 与 Markdown 共用 DOMPurify 和应用自带的视口加载器。远端文件作为 Base64 文本传入，清理后用 DOM 节点插入；HTML 的静态样式、标题与 body 的样式属性继续保留。CSP 只允许带本次 nonce 的应用脚本运行，不运行文件自己的脚本、事件属性或 iframe，也没有 NativeTerminal 或新增 Android JavaScriptInterface。

HTML 图片保留原 DOM 父子关系，不用新增 a 包装，避免影响原 CSS 子选择器。原生短按通过加载器的只读 Blob 映射查找原文件路径；已有链接的图片继续遵守其作者指定的链接。失败提示用单独的重试按钮，保留图片原来的 alt。

视口更新通过文档专用、带随机 capability 的虚拟 HTTPS 路由传入。只有该视口授权的图片请求能进入 SFTP；普通 HTML/CSS 提前发出的图片请求不产生远端下载。所有文件仍遵守 canonical/目录范围、类型和单文件限制。

独立 SVG 继续以 WebView 的 img 图像模式打开，页面 JavaScript 关闭；内嵌 SVG 也是图像模式。没有新增 Android/JavaScript 推理或渲染依赖。

## 验证入口

- `npm --prefix web test`：包括视口范围、当前屏幕优先、滚动速度与跳转判定。
- `npm --prefix web run test:browser`：既有终端回归与真实打包预览页；覆盖 Markdown/HTML 完整文本、快速跳转不下载沿途图片、缓存返回、超过 32 文件、折叠、重试、CSS 背景、慢下载取消、脚本隔离及大型平铺 HTML。
- `PreviewCacheTest`：LRU 淘汰、响应流与淘汰并存、容量边界、系统清理、默认设置、迟到请求与取消。
- `PreviewLoadingTest`：真实 SSH/SFTP + Android WebView 的 40 图片、快速跳转、缓存复用/淘汰、大 SVG、设置持久化和位图采样。
- `PreviewInteractionTest`：保留原有预览、文件路径、像素/缩放、绝对路径、安全与临时文件清理回归。

本地原始记录放在 `.tools/diagnostics/preview-window-final/` 和对应 Android matrix 目录，测试范围与结果另见[实现验证记录](../testing/preview-viewport-cache.md)。
