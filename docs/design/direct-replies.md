# 快捷回复与语音编辑发送

2026-11-02，基于 `a21fd17`，未发布。采用保留语音编辑框、点击发送时直接提交的交互。

## 快捷回复

点击回复即通过既有粘贴通路发送文本和 Enter，不再经过本地草稿或追加/替换确认。编辑图标继续修改保存的回复。

打开回复面板时捕获连接 token 与草稿目标，点击时重新核对；重连或目标改变时不发送。发送期间忽略重复点击，远端写入仍校验 pane 身份、焦点、copy-mode 与同步输入条件。

请求携带 `clearDraft=false`，即使快捷回复与当前本地草稿完全相同，成功回调也不清空或改写草稿。文本和 Enter 由 xterm 按实际粘贴模式编码，通过同一有序写入操作送出；控制字符、多行和容量校验沿用既有逻辑。

## 语音编辑框

转写后继续显示可编辑卡片，不在识别完成时自动发送。voice 版设置新增“编辑后直接发送”，默认开启，存储在 `terminal-settings/voiceSendWithEnter`。

- 开启：语音草稿按钮为“发送”，一次提交文本和 Enter。
- 关闭：按钮为“插入终端”，仅插入文本，由用户另按 Enter。
- 手动新建的文本草稿保持原有插入方式；快捷回复始终直接发送。

语音来源按草稿目标在当前进程保存，关闭再打开、切换目标再返回仍可识别已有语音草稿。成功发送清空当前匹配的草稿及其来源；快捷回复不清除该标记。新建空白手动草稿和工具中的清空操作会移除旧来源。

SharedPreferences 监听让设置修改及时反映到编辑卡片，释放组件时注销。standard 版不显示设置，也不注册语音发送设置监听，不新增语音依赖或权限。
