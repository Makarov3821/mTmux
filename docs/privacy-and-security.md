# 隐私与安全说明

本页集中说明当前实现的数据处理与边界。实际操作入口见 [使用指南](usage.md)。

## 服务器资料与凭据

服务器地址、用户名、分组、主机信任和最近任务等资料保存在应用私有存储。密码、导入的私钥及口令使用 AES-GCM 加密，包装密钥由 Android Keystore 管理；连接目标与认证上下文参与校验。

凭据无法解密时需要重新输入。应用禁用 Android 备份和设备迁移；卸载或清除应用数据会删除配置、凭据和信任记录。当前没有账号登录或云同步。

## 主机指纹与远端操作

首次遇到目标服务器或跳板主机时，需要核对展示的 SHA-256 指纹。添加服务器时多级主机逐级核对，验证通过并保存时写入信任记录；Save anyway 只保存配置，不信任验证失败过程中遇到的新密钥。

主机密钥变化会阻止连接，当前没有覆盖单条旧指纹的入口。先通过管理员或可信终端核对变化；清除应用数据会同时失去所有配置与信任记录。

Doctor 的检查读取环境，不自动安装软件。首次配置需满足初始化条件、预览并确认，已有配置不会被覆盖；撤销保留备份并检查文件是否已改变。具体条件见 [Doctor 说明](testing/tmux-doctor.md)。

## 终端、草稿与文件预览

终端输出和编辑草稿保留在当前进程中。重连不会重放旧输入；目标变化或连接失效时发送会被拒绝。tmux attach 与其他客户端共享显示焦点和尺寸，普通 shell 的进程存活取决于远端环境。

文件预览通过当前 SSH 的 SFTP 通道读取，使用同一登录用户的远端权限；支持相对路径、远端绝对路径及当前主机的文件 URI。应用不会替用户推断 Agent 在其他项目中的工作目录，路径可由用户修改。

下载内容写入应用私有缓存。单文件默认 10 MiB，本次预览缓存默认 50 MiB；正文完整读取，图片按视口加载，缓存按最近使用淘汰。正常关闭会清理该次缓存，应用启动也会清理未活动的旧预览目录；异常退出不保证立即删除。容量可在设置调整，细节见 [缓存设计](design/preview-viewport-cache.md)。

文档 HTML 会清理后渲染，不执行远端页面脚本，也不在预览中直接加载互联网资源；应用自身的图片加载代码在单独预览 WebView 中运行。SVG 使用图片模式。外部网页交系统浏览器，本机地址会先显示目标供确认。预览与终端的 JavaScript 桥接相互独立。

## 语音、日志与系统组件

voice 的录音与 X-ASR 转写在本机完成，不调用云语音服务。音频与转写正文不写入诊断日志，录音不保存为音频文件。用户确认插入终端后，文本会通过 SSH 发送到远端。standard 不包含语音模型与运行库，也不声明麦克风权限。

诊断日志记录版本、运行阶段、固定错误类型、耗时、输入连接状态、终端尺寸及字节计数等，不记录密码、私钥、命令、终端正文或转写文字。内部最多保留最近 10 MiB，跨重启保留，导出由用户发起；应用不会自动上传日志。系统结束进程、原生崩溃或存储故障不保证留下最后一条记录。字段说明见 [连接性能与日志](testing/connection-performance.md)。

系统输入法、剪贴板和系统浏览器有各自的数据处理行为。自定义别名、终端输出和用户主动导出的文件可能包含敏感内容，应由用户选择如何分享。

## 隐私展示与截图

隐私展示默认开启，并保存在本机：

| 场景 | 当前行为 |
| --- | --- |
| 隐私展示开启 | 自动展示的连接地址和用户名隐藏，普通页面允许截图 |
| 隐私展示关闭 | 恢复展示连接信息，应用禁止截图与录屏 |
| 凭据编辑、私钥粘贴、完整连接详情、指纹核对 | 始终禁止截图与录屏 |
| 最近任务预览 | Android 13+ 禁用系统预览截图，应用暂停时也启用安全窗口标志 |

自定义名称和终端正文不自动脱敏。系统截图与最近任务实现的具体表现仍需结合设备验证，已有结果见 [测试流程与记录](testing/webview-and-release-runbook.md)。
