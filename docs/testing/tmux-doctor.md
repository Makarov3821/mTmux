# tmux Doctor 使用与实现说明

随 0.9.0 发布，适用于 standard 与 voice；最低兼容 baseline 为 tmux 3.2a。

## 使用入口

新增服务器经主机身份检查、指纹确认和 SSH 认证并保存成功后，弹出可选邀请。“暂时跳过”回主页，“运行 Doctor”打开诊断弹窗。服务器卡片三个点菜单也可以重复运行 Doctor。已有指纹仍会验证，一致时无需重复批准。

跳过、诊断失败或取消都不撤销已完成的保存。SSH 验证失败时原有 Save anyway 仍保留；后续手动运行 Doctor 须完成正常认证和必要的指纹确认，不会绕过主机身份验证。

## 报告内容

检查应用本地的远端触摸转发开关，关闭时警告并提供开启按钮；不会出现只有远端 mouse on 就全部通过的误导。逐项显示 SSH、可执行路径、版本、会话访问、任务信息格式、鼠标、滚轮、历史、会话保留、同步输入、辅助命令、显示环境和用户配置。使用通过、警告、失败和未检查四类结果；读取期间显示进度。旧报告带历史时间，失败不会冒充新一轮检查成功。

- 小于 3.2a 在版本行警告，不做旧版任务协议降级，也不将旧版当成未安装。
- 没有运行中的 tmux server/会话是正常状态；依赖它的运行时检查保留待检查，Doctor 不主动创建会话。
- 抽查上限为 16 个会话、32 个 pane，报告注明抽查范围，不下载 pane 正文或历史。
- 不要求 root 显式绑定 WheelDownPane；识别常见历史绑定及步长，复杂自定义逻辑提示实测，保留原设置。自定义绑定正文不进入报告缓存或日志。
- 配置文件、全局默认及已有 pane 的实际容量分开判断。历史默认值改变不等于扩大已有历史。

## 最小配置初始化与撤销

已安装且达到 baseline、当前没有 server、标准/XDG 用户配置不存在、HOME 可写且属于登录用户、所需文件工具可用时，提供最小配置预览。脚本/包装器等无法确认加载方式的可执行文件不走自动初始化。用户还须确认首次配置且没有其他自定义配置/socket。

默认内容为 mouse on、10000 行历史、destroy-unattached off、exit-unattached off；历史可选 2000～500000 行。预览显示当前远端登录用户的实际目标路径，确认后才写入。

创建使用同目录的私有临时文件、内容摘要与 `ln -T` 排他发布，不覆盖已有文件、链接或目录；竞争失败时保留现有目标。应用不 sudo、不安装插件、不覆写系统配置、不整文件 source 现有用户配置。

成功后保留与连接修订、文件 inode/所有者和摘要绑定的撤销凭据。撤销只接受仍未被修改的文件，并保留私有备份；过程中检测到外部变化时拒绝删除，必要时保留备份以免内容丢失。若网络中断导致结果无法确认，先重新诊断，重试不会覆盖已有文件。

配置创建后标明等待 tmux 下次启动加载。主页创建初始化后的首个会话时，额外复查一次；配置文件撤销不修改已经运行的会话设置。

## 主页新建入口

近期明确确认当前 tmux 路径不可用时，创建按钮及对应菜单项置灰，普通 SSH 与 Doctor 保留。失败记录五分钟后本地过期，恢复“点击先检查”的入口；不在后台不断重连。编辑连接参数、凭据、信任身份或 tmux 路径会使旧记录失效。删除服务器清理报告、能力记录和撤销凭据。

未检查/过期状态先进行轻量可用性检查；正常时进入命名窗口。低版本或未知版本会保留版本提醒，让用户确认继续。实际新建仍检查可执行性和重名，不能只相信缓存。普通网络失败、名称重复、鼠标/历史建议不会被记作 tmux 未安装。

显式刷新发现 tmux 已恢复时也会更新可用性。折叠分组限制、首页自动刷新间隔和返回终端后的定向刷新规则继续生效；近期已知不可用的服务器跳过无意义的自动重复嗅探，仍允许手动重试。

## 连接与日志

Doctor 等待同服务器正在执行的首页刷新结束，优先取得已认证的连接；取消或完成后归还连接池或按用户档位关闭。阅读报告和配置预览不额外保留 SSH。“无保留”仍不持有空闲连接，后续动作需要时重新认证。

只读批量命令预算五秒，配置创建/撤销单条命令也设置明确预算。显式预算覆盖通道建立和命令等待；其他既有 exec 调用保留原有超时策略。

诊断与配置操作有独立日志事件和 SSH phase，不记录命令、凭据、终端正文或自定义绑定内容。旧连接配置的迟到结果不能覆盖当前修订。

## 验证

核心测试包含版本后缀/数字比较、五分钟过期与修订失效、多行中文记录解析、缺失可执行文件与无 server 的区别、版本警告、默认/自定义绑定判断、初始化条件、已有文件/链接保护、并发排他创建、修改后拒绝撤销及备份保留。

本地一次性 OpenSSH 测试验证同链诊断只进行一次握手，以及超时命令关闭后连接仍可用。Android 测试覆盖跳过邀请、版本行、主页限制及过期、断网保留服务器，另用一次性 SSH fixture 验证完整保存与 Doctor 复用流程。具体执行结果见本轮 [证据目录](../evidence/tmux-doctor-20261029/) 和提交说明；主流旧版仓库调研见 [兼容性报告](../design/tmux-compatibility-research-20261029.md)。

范围限制：没有在所有发行版、所有 Android 真机和所有 Agent 上完成端到端测试；TUI 的内部滚动仍由程序实现。已有复杂配置只提供基础建议，不自动编辑。
