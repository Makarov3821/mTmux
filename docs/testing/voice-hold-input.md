# 按住说话与录音光晕

> 历史方案与试验记录：当前主应用的识别引擎、模型开关和构建方式以 [X-ASR 迁移记录](voice-xasr.md) 为准；按住录音与编辑交互仍保留。

2026-10-23，基于 0.8.4 的未发布修改；按住录音阶段最初保留 base q5_1；后续已按用户要求改为 q8 + 可关闭的离线标点恢复，并提供轻量 SRF 对照构建。当前模型、包体和结果见 [模型试验记录](voice-models-20261023.md)。固定模型校验及完全本机转写保留。

## 交互

1. 按下中央语音按钮后立即准备麦克风。准备期间显示中性光晕和“准备中”，不把这一阶段计入录音倒计时。
2. 麦克风实际启动成功后显示绿色光晕，中央显示剩余秒数，从 60 秒开始。剩余 10～5 秒由绿渐变到橙，5～0 秒由橙渐变到红。
3. 松手结束并转文字。录音上限同时受音频采样数和单次 60 秒定时保护，两者或松手同时触发也只会转写一次。
4. 从按下位置向上移动至少 72 dp 进入取消区，光晕变红并显示“松手取消录音”；此时松手丢弃音频，移回后恢复正常录音。手势使用窗口坐标，收起软键盘导致按钮移动不会被当成上滑。
5. 准备好前松手、系统取消触摸、额外手指中断、按系统返回、退后台、切换连接/目标或发送变为不可用时取消当前录音。旧会话的迟到回调不能重新点亮录音或停止新会话。
6. 首次权限弹窗会结束原手势，授权后提示重新按住，不在授权回调中自动开始录音。无障碍点击提供“点击开始／再次点击结束”，无需持续按住。

录音反馈采用不获取焦点的覆盖层，既有底栏仍为 156 dp，不调整 WebView 或远端终端网格。倒计时只在录音期间更新，无空闲动画或后台监听；光晕为渐变绘制，不做背景模糊。松手后才打开原有转写/结果面板。

结果沿用草稿规则：空草稿直接填入；已有草稿展示追加、替换和取消；用户确认发送前不写入 SSH。不会把音频、转写正文或提示词写入日志。

## 并发与资源

- `VoiceHoldState` 用会话代次区分准备、录音、转写、结果和错误，准备好回调与每次停止/取消均校验所属会话。
- 麦克风的开始、停止和丢弃使用同一个后台执行队列。丢弃等待采集工作线程退出，不将取消的 PCM 转换为浮点数组；快速取消后再次按住不与上一段采集交叠。
- 排队中的旧停止操作执行前再次校验代次，避免停止已经开始的新录音。旧转写结果不能清除新转写的取消句柄。
- 推理任务取消后清理尚未执行的请求 ID；取消原生推理仍使用既有 abort callback，不增加模型常驻或后台推理。

## 标点与模型

检查改版前的 JNI：使用 base q5_1、greedy 解码、固定/自动语言；拼接分段结果并 trim，没有主动删标点，没有独立标点恢复模块，也没有设置风格示例 prompt。

对 Agent 的影响属于使用判断：短的自然语言请求通常能从上下文理解，但长句、多项约束、否定范围、引用及命令/路径更易产生歧义。尤其不要把需要精确符号的代码或 shell 参数当成能由语音自动恢复的内容；继续在发送前编辑草稿。

候选路径：

| 路径 | 可期待的收益 | 需要验证的成本或限制 |
| --- | --- | --- |
| base + 风格示例 prompt | 小幅尝试断句风格，不增加模型文件 | Whisper prompt 是上下文/样例，不是指令；中文录音 A/B 验证标点、漏字和幻觉后才能启用 |
| Whisper small 等较大模型 | 作为整体识别质量对照 | 不保证单项标点收益；包体、CPU、内存和停录到结果的延迟需要 ARM 真机测试 |
| 独立中英文标点恢复模型 | 明确针对无标点转写文本 | 新增模型、运行时及推理；需保护代码、路径、参数及原句意思，保持可编辑和不自动发送 |
| SenseVoice 等不同 ASR | 可作为中文/中英混合识别对照 | 官方作者报告了中文优势，但不能直接当成本机、技术词或标点质量保证；仍需同一批实际录音对比 |

后续已完成 q8、CT/SRF 标点模型对照接入，设置可关闭补标点；不改写原有字符及空格，现有标点与检测到的技术片段保留。上述表格保留当时的候选分析；最新验证与限制见模型试验记录。

资料：[Whisper 模型速度/精度取舍](https://github.com/openai/whisper#available-models-and-languages)、[Whisper prompt 的风格样例机制](https://developers.openai.com/cookbook/examples/whisper_prompting_guide)、[FunASR 的独立 ct-punc 标点模型](https://github.com/modelscope/FunASR#usage)、[SenseVoiceSmall 作者模型卡](https://huggingface.co/FunAudioLLM/SenseVoiceSmall)。官方 Whisper 速度表基于 A100/英文，并不是手机延迟或内存测量。

## 验证

- 新增 `VoiceHoldStateTest` 7 项，覆盖准备完成才计时、准备中释放与迟到启动、只转写一次、上滑取消及迟到结果、移回继续和超时、切换目标/取消后旧回调失效、无障碍开始/结束。
- 原有 Voice Android UI 用例改为注入真实按下/松开事件，等待录音准备完成后再释放，保留不自动发送断言。
- standard / voice 的 Debug 单元测试各 22 项通过，voice 模块 4 项通过，均无失败或跳过。两版 Debug APK、Android 测试 APK 均构建成功；两版 Debug lint 均为 0 错误（standard 76、voice 49 条警告）。完整构建记录为本机 `/tmp/mtmux-voice-hold-final.log`。
- 此环境没有连接的 ARM 真机；Android 手势、麦克风、键盘收起时的按钮移动、实际 60 秒录音和提示配色仍需设备验收，未计为已运行通过。
