## 0.0.2 输入与显示回归

- 输入 `pwd` 后点击“发送并回车”：终端显示命令结果，输入框清空，不能只发送空回车。
- 输入法回车仍用于换行；快捷 Enter 在有草稿时发送草稿并回车，无草稿时发送单独回车。
- “仅粘贴”只写入文本，另点 Enter 才提交；不能因为输入框未清空而重复粘贴。
- 输入时断网：结果不确定时保留草稿，不自动重试。
- 键盘展开、横屏及大字号：终端不会被测量为零高度；小窗口可滚动整个工作区，顶栏可收起键盘。
- 没有远端输出时有明确等待提示；工具面板显示已解析字节数（不等同于屏幕已绘制），便于区分未收到输出和显示异常。

## 0.0.3 空白终端回归

- 覆盖安装后打开普通 shell，未输入任何命令前就能看见服务器提示符（欢迎语取决于服务器配置）。
- 工具中的行数应随可用高度变化，不应一直是 1；字节数只表示进入解析器。
- 输入 `pwd` 并点击“发送并回车”，应同时看到执行结果和清空后的输入框。
- 切换配置、打开和收起软键盘后，输出仍然可见。
- Android 15 模拟器已通过合成 SSH 和屏幕像素回归；用户手机尚待复测。

- 保存两个服务器配置，切换后地址和认证方式正确；关闭应用再打开可恢复最近配置。密码需重填、私钥需重新导入；编辑/删除一项不覆盖另一项。
- 打开包含自定义中文会话/窗口名称的 tmux：看到名称与索引，改名后重新发现可刷新；仍明确按 session 接入。

- tmux 点击“tmux 历史”，选择 pane，可以读取手机连接前的已有历史；滑动、刷新、返回实时终端均可用，电脑端焦点和 copy-mode 不改变。
- 手动断开后显示清空，按钮不可向远端发送，本地草稿保留；另一客户端和 tmux 内任务仍运行。

- 在真实 Agent alternate screen、tmux mouse 开/关两种配置下重复阅读测试；手指滑动不应触发 Agent 操作。实时输入的共享焦点仍是已知限制。

## 0.1.1 用户反馈回归（替代旧版“不保存凭据/不发送鼠标”的预期）

- 旧配置补充密码或私钥及口令，点击保存；完全关闭并重新打开应用后，点击“连接 shell”或“连接 tmux”，无需再次填写凭据。分别测试密码、未加密和加密 OpenSSH 私钥。
- 修改一项配置、切换另一项、删除一项：凭据不能串用，被删配置的密文应移除；首次指纹校验及密钥变化拦截继续有效。
- 使用用户现有 mouse/history-limit/WheelUpPane/WheelDownPane 配置：在实时 pane 内容区域上下滑动，看历史位置变化；无需打开历史快照；点击“退出 tmux 滚动”可返回。
- 在 Codex CLI、OpenCode、Kiro CLI 的具体版本中分别验证滚轮、左键、长按松开的右键；记录版本及 TUI 是否启用鼠标。滑动结束不应误点击。
- 点击另一 pane 或 tmux 状态栏应遵循电脑端同样的绑定；操作可能改变共享焦点，这是预期的当前接入行为。
- 工具关闭“触摸发送滚轮和点击”后只滚动本地历史；断线或换连接后，旧手势不能继续发送。
- 主终端实时滚动不受快照 2000 行限制；服务器已经丢弃的历史不能恢复。不要把快照或手机 scrollback 限制误认为服务器历史上限。

## 0.1.2 连续慢拖回归

- 在有文字的行上按住，缓慢向下移动 2–3 秒，中途不抬手：前、中、后三段都应推动历史。再从空白处开始对照；持续有输出时重复。
- 按住不动应停止，保持按住并反向移动应及时改方向；松手后无继续滚动、无误点击。
- 快速短划仍有响应；连续多次划动能继续读历史，轻点切 pane 与长按右键仍正常。
- “工具”调整远端滚动速度至 0.5× / 2×，关闭重开应用后保留设置；小屏或横屏下工具内容可以滚动查看。
- 用实际 Codex CLI、OpenCode、Kiro CLI 分别复测，记录版本与手感；模拟器与合成 TUI 通过不等于这些程序都已验收。

## 0.1.3 回复目标保护

- 手机打开 pane A 并填写回复，电脑切至 pane B 后点击发送：A/B 都不应收到，手机保留草稿并提示未发送；切回 A 后重试只能到 A。
- 清空草稿后点“使用当前 pane”绑定 B；新回复仅到 B。B 已有草稿时应恢复 B 的草稿，不能把 A 的草稿自动搬过去。
- 同样验证快捷 Enter/Ctrl-C、仅粘贴后切换焦点再 Enter、不同窗口、pane 被关闭/respawn、copy-mode 与 synchronize-panes；不得误发到其他 pane。
- 断线不自动重放；新连接身份不同不能自动载入旧 pane 草稿。鼠标点击/滚轮与共享尺寸保留原行为。

## 0.1.4 最近任务与安全重连

- 成功进入两个不同任务，彻底关闭再打开 App：最近任务显示名称，点击无需重填凭据，进入选定原窗口/pane；最多保留 10 条。普通 shell 明确开启新连接。
- 写入未发送草稿后退后台再返回，或 Wi-Fi/蜂窝切换导致断线：不自动连接/重发；点击重连同一任务后保留当前进程的草稿，远端没有自动收到正文或 Enter。杀进程后不承诺草稿恢复。
- 电脑切到其他窗口后重连：返回记录的 pane，检查电脑共享焦点变化，确认未踢掉电脑客户端。
- 原 pane 被关闭、respawn 或 tmux 服务重启且 ID/名称复用：拒绝恢复，点击“重新选择任务”刷新列表后由用户明确选择。
- 主机密钥变化、认证失败、网络不可达：失败有提示，最近任务不被失败尝试覆盖；不静默接受新主机密钥。
- 修改服务器地址/端口/用户名/tmux 路径清除关联任务；改显示名称不丢任务，删除服务器清除关联记录。

## 0.2.0 首页与多级跳板

- 覆盖安装后旧服务器/凭据仍在；首页立即显示缓存，自动刷新；手动刷新只更新对应服务器。离线保留子项并显示失败，进入终端前仍核对身份。
- 返回首页或首页退后台再回来重新刷新；没有自动 attach 或自动发送草稿。编辑后保存关闭表单，离线也能保存。
- 新增/编辑表单基本字段正确，高级默认折叠；未保存修改退出时确认放弃。折叠服务器后 SSH/刷新/更多仍可用。
- 两级以上跳板使用真实不同服务器，分别测试密码、私钥及带口令私钥；调整顺序后凭据仍跟随对应级。每一级核对指纹，错误显示失败级别，不回退直连。
- 经跳板分别发现 tmux、连接 shell、接入指定 pane 和断线重连；退后台、返回首页或连接中取消后应释放全部连接。
- 改目标或跳板链后旧缓存/最近任务失效；改别名保留。删除不影响远端任务，也不清除其他配置仍引用的主机信任。
- 首页设置中的字号/速度/触控方式重启后保留；小屏、横屏及键盘弹出时表单与设置可滚动，保存/取消可达。

## 0.2.1 首页刷新与密度

- 返回首页、切换设置页返回、应用重启：上次嗅探不足 15 分钟不自动连接；达到 15 分钟后再次进入首页才刷新，没有后台定时嗅探。
- 每台独立计时；失败后也等待间隔，手动刷新立即触发。首次添加和修改目标地址/跳板链后重新嗅探。
- 有别名时地址行隐藏，更新时间紧邻名称；长名称不挤掉右侧三个按钮。无别名显示用户名/地址，离线错误和指纹确认提示仍可见。

## 0.3.0 终端布局与键盘锚点

- 顶部只有返回、当前服务器/会话/窗口和回到底端；有别名不展示地址，长名称点击查看。终端无框，底栏工具/收起键盘/发送回车，历史快照与独立退出滚动入口移除。
- shell 历史、tmux copy-mode、实际 Codex/OpenCode/Kiro 的全屏视图：暂停输出时，在中间停留，反复点击回复框和收起键盘，顶部相同内容与位置应保持，不重绘回放、不退出历史。
- 键盘展开时点击回到底端能显示底部；tmux copy-mode 仅取消核对后的当前 pane，不发 Esc/Ctrl-C。再测试点击坐标、滚轮和新输出；Agent 内部阅读状态不保证能统一跳转。
- 草稿较长时回复框内滚动，终端网格不受影响；收起键盘后正常恢复可见范围。旋转与字体变化正确 resize，横屏/大字号/不同输入法需真机确认。
- 工具中的仅粘贴、多行预览、回复目标重新绑定仍能使用；目标改变拦截、断线标记和安全重连保留。

## 0.4.1 刷新与文件夹

## 0.6.1 首页灯与底部快捷回复

- 首页每个 tmux 名称前显示红/黄/绿/灰点；真实 Agent 的确认、错误、运行和明确完成提示分别核对。颜色是上次刷新结果，不能将沉默视为完成。
- 多 pane 窗口含需处理时红、否则运行时黄；有未知成员不显示全完成绿，展开看各 pane。
- 刷新失败或超过 30 分钟后变灰；折叠文件夹不自动探测，从终端返回不触发刷新，手动服务器/文件夹刷新更新状态。
- 电脑同时使用时，首页刷新不切换焦点、不改变 copy-mode；任务重建不得沿用旧 pane 的颜色。
- 终端没有状态卡，底部顺序为工具、收起键盘、快捷回复、发送回车；窄屏与键盘开关后不挤压/换行，草稿仍需显式发送。

### 0.6.2 状态灯回归

- 覆盖安装后手动刷新服务器，检查已完成的 Kiro / OpenCode / Codex 在采集结束时就显色，不再等待一分钟。
- Kiro 回到输入提示、OpenCode 回答结束或原生就绪标题应为绿；运行中应黄；可识别审批/待处理提示应红。绿表示结束/就绪，不保证任务目标成功。
- 上一轮完成后再发新任务，手动刷新时应优先识别当前运行/审批，不延续旧绿。
- 多 pane / 多服务器测试分批显色，同时确认电脑上的 tmux 焦点、历史模式不受刷新影响。
- 标题被禁用或版本/主题差异导致未知时，保留脱敏底部画面用于回归；本轮没有安装远端插件，不是实时事件监控。
