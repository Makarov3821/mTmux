# 0.1.1：保存凭据与实时终端触控

2026-09-23。APK `app/build/outputs/apk/debug/app-debug.apk`，versionCode 5，可覆盖安装。此版本修正 0.1.0 未满足用户预期的两处行为；整个 P1 仍未整体验收。

## 配置保存后直接连接

保存配置现在包含 SSH 密码、导入的私钥文件及私钥口令。凭据使用 Android Keystore 中的 AES-256 密钥与 AES-GCM 加密，密文和配置在一次 SharedPreferences 提交中更新；每次加密使用新的随机 IV，并将配置 ID、地址、端口、用户名和认证方式作为认证附加数据，拒绝密文篡改及跨目标替换。没有明文保存回退，也不上传凭据。

重建界面后载入凭据，列表提供“连接 shell”和“连接 tmux”；后者发现会话后按名称选择，避免按过期 session ID 静默接入新任务。首次主机指纹核对和主机密钥变化拦截仍然保留。删除配置同时删除对应密文；应用备份和设备迁移均关闭。

0.1.0 的配置本来没有凭据，不能凭空恢复：升级后填写密码或导入私钥并保存一次即可。设备包装密钥丢失、凭据损坏时提示重新输入，不以空凭据覆盖旧密文；不额外要求生物识别。包装密钥不等于 SSH 私钥，也不承诺每台设备都硬件托管。

## 直接操作实时终端

- 手指向下拖动对应鼠标滚轮向上，向上拖动对应滚轮向下；轻点一次发送左键按下与释放，长按后松开发送右键。
- xterm 根据远端协商的鼠标协议编码，兼容 SGR 与传统二进制坐标。二进制报告通过独立字节桥传输，避免 UTF-8 重新编码破坏坐标。滑动结束不生成点击，多指/取消/切换连接后不发送残留手势。
- 不请求鼠标的普通 shell 使用本地滚动；不擅自将全屏程序的滑动替换成方向键。“工具”可以选择仅滑动手机本地历史。
- “连接时为此 tmux 会话开启鼠标”默认勾选，执行会话级 `set-option -t <session> mouse on`；不改配置文件、全局选项、历史上限或滚轮绑定。此设置对同一 session 的电脑端也有效，断开后不自动还原。
- “退出 tmux 滚动”发送 tmux copy-mode 的 cancel，不向 Agent 发送 `q` 或 Esc。Agent 自己的滚动状态仍由其程序处理。
- “历史快照”仍可使用，但只是辅助入口。快照的 2000 行、本地 scrollback 的 3000 行上限都不截断实时 tmux 的服务器历史。实际可读内容由服务器已保留的历史决定。

点击 pane、点击状态栏、在 copy-mode 阅读的影响与电脑鼠标一样，仍共享当前 tmux 状态。底部状态栏不是 pane 内容区，滚轮可能按用户绑定切换窗口。拖拽选择、拖拽调整 pane、悬停和多指缩放尚未实现；本次不宣称完全替代桌面鼠标的所有动作。

## 用户配置复现

用户使用 Codex CLI、OpenCode、Kiro CLI，提供了以下桌面 tmux 配置。已原样用于临时测试服务器；没有访问或修改用户真实服务器的文件。

```tmux
set -g mouse on
set -g history-limit 500000
bind -n WheelUpPane {
    if -F '#{||:#{pane_in_mode},#{mouse_any_flag}}' {
        send -M
    } {
        copy-mode -e
    }
}
bind -n WheelDownPane {
    if -F '#{||:#{pane_in_mode},#{mouse_any_flag}}' {
        send -M
    }
}
```

新终端把真实滚轮事件交给这些绑定：普通 pane 进入 tmux 历史，已在历史中继续滚动，启用鼠标的 TUI 接收滚轮。这解释了旧版仅移动本地 viewport 为什么无法实现相同行为。

## 验证结果

环境：Android 15 / API 35、WebView 124.0.6367.219、720×1600 / density 320，tmux 3.4。SSH 使用临时 Ed25519 密钥和独立 socket。

- 10 项 Android 用例全部通过，无跳过；先验证默认 tmux 绑定，再用上述用户配置重跑全部通过。
- 明文与带口令的 OpenSSH 私钥分别加密保存，Activity 重建后点击已保存配置直接完成真实 SSH 认证；密码恢复、密文中没有原始秘密、随机 IV、跨服务器/篡改拒绝、删除凭据也已测试。密码认证本身未在本次临时服务启用，未将其记为新端到端通过。
- 实际手势改变远端 `scroll_position`，可双向滚动并退出 copy-mode；点击右侧 pane 后远端活动 pane ID 变化。
- 全屏合成 TUI 启用 alternate screen 和鼠标模式，实际收到向上/向下滚轮与一次点击，滑动阶段点击计数为零。已检查截图中的输出，不仅检查 JS 缓冲。
- 11 项核心/SSH 测试通过，4 项终端解析测试通过；浏览器验证 SGR 点击/释放、左右键、上下滚轮、传统二进制报告和换连接取消手势；debug 编译与 Android lint 通过。

## 参考与后续
