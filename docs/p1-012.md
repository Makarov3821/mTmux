# 0.1.2：连续慢拖与滚动手感

2026-09-23。versionCode 6，versionName 0.1.2-dev，可覆盖安装。APK：`app/build/outputs/apk/debug/app-debug.apk`。

## 原因与修复

用户反馈按住缓慢下滑时，终端仅开始跳一下，后续不动。Android 15 实际按住连续拖动复现：从文字区域开始的触摸，在 xterm DOM renderer 替换文字节点后丢失后续事件；从空白处开始则可能通过。之前的快速 swipe 测试没有覆盖这个差异。

终端新增不随文字重绘替换的透明触控层，保证一整段手势持续传递。位移保留小数；超过 8 CSS px 才认定为拖动。第一格滚轮较快响应，后续默认每三行手指位移发送一格滚轮，降低 tmux 默认每格滚多行导致的放大感。每帧最多发送一格远端滚轮；反向清除旧方向积压，松手清除剩余队列。若极快划动在下一动画帧前结束，松手时最多提交一格，避免整段被丢弃。

“工具”新增远端滚动速度 0.5–2×，默认 1×，保存在本机，重启继续使用。工具内容支持滚动，适应小窗口。协议仍由 xterm 编码，用户服务器的 tmux 绑定保持原样。普通 shell 的本地历史滚动也使用稳定触控层；速度设置只影响远端滚轮。

## 验证

- Android 15 模拟器、720×1600 / density 320，隔离 OpenSSH + tmux 服务，使用用户提供的 mouse/history-limit/WheelUpPane/WheelDownPane 配置。
- 从文字区域开始实际按住约三秒，分三段各注入 12 次慢速移动，中途不松手。修复前仅收到 touchstart，历史位置 0；修复后历史位置依次为 **5 → 10 → 20**。已检查历史截图中的内容和 `[20/137]` 标记。
- 10 项 Android 回归全部通过，无跳过：包括慢拖、快速反向划动、点击 pane、全屏合成鼠标 TUI、本地历史、输入/显示、断开和凭据恢复。
- Chromium 浏览器回归通过：重绘后触控层仍命中、连续细小移动、停住不动、反向、松手无尾部事件、同帧快速划动、SGR/传统二进制鼠标与连接切换取消手势。
- 终端解析测试、最终 APK 编译与 Android lint 通过。完整 Android 回归后仅微调工具文案、滑块刻度及对话框滚动布局；这些最终 UI 微调通过编译/lint，尚未在真机检查。
