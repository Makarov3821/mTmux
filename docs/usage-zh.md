# 使用指南

[English](usage-en.md) · [简体中文](usage-zh.md)

本指南对应主分支当前实现。已发布版本的变化见 [CHANGELOG](../CHANGELOG.md)。

## 安装与服务器准备

在 [Releases](https://github.com/Makarov3821/mTmux/releases/latest) 选择 standard 或 voice APK。两者使用同一应用 ID，选择一种安装；voice 增加离线语音输入，包体更大。

手机需要 Android 8.0 或以上版本。服务器需要 SSH 服务、登录账号与 tmux，文件预览还需要 SFTP 服务。建议使用 tmux 3.2a 或以上版本；低于此版本时 Doctor 会提醒升级。

首次准备 tmux 时，可以从以下配置开始：

```tmux
set -g mouse on
set -g history-limit 10000
```

已有配置可按需合并这两项。`mouse on` 用于触屏滚动与点击，历史容量的修改通常影响后续新建的窗口。自定义滚轮绑定的检查和版本依据见 [tmux Doctor](testing/tmux-doctor.md)。

## 添加服务器

1. 在首页添加服务器，填写别名、地址、端口和用户名。
2. 选择密码或私钥认证。私钥可以从文件导入或粘贴；加密私钥另填口令。
3. 点击保存，应用会主动连接、展示尚未信任的主机指纹并验证认证。核对后选择继续；多级跳板会逐级核对。
4. 验证通过后保存并回到首页，可选择运行 tmux Doctor。

验证失败时，可以返回编辑、重试，或选择 **Save anyway** 保存配置。未验证保存后可在服务器菜单使用“验证指纹”，也可在后续连接时继续验证。主机密钥变化的处理见 [隐私与安全说明](privacy-and-security.md)。

粘贴私钥时包含完整的 BEGIN／END 行，私钥口令填写在认证区。支持 OpenSSH／PEM 文本私钥；格式检查通过后，实际可用性仍由 SSH 认证验证。

需要跳板时，在高级选项开启 Jump Host，按“手机 → 跳板 → 目标服务器”填写，或从已保存服务器复制。复制会包含其跳板链，之后修改原服务器不会同步到这份副本；服务器需要允许 SSH TCP 转发。高级选项也可修改 tmux 可执行路径。

“会话鼠标”默认开启，连接时为所选会话启用鼠标支持，也会影响连接同一会话的电脑客户端；该选项不重写 `.tmux.conf`，断开后不会自动还原会话设置。

## 首页、刷新与会话

点击已有 tmux 项进入对应终端；多 pane 的窗口可展开选择。服务器的新建按钮会要求输入独立会话名，检查重名后创建并进入。普通 SSH shell 入口也可直接使用。

可以新建文件夹、移动服务器、搜索和调整排序。下拉刷新会更新未分组和已展开分组中的服务器；单台服务器也有刷新入口。

冷启动或从后台回到首页时，自动刷新间隔为每台服务器 5 分钟。从终端返回只对刚使用的服务器跳过间隔，仍遵守折叠分组限制。其他服务器按正常间隔处理。

任务颜色表示最近一次刷新时的状态：红色可能需要处理，黄色表示运行中，绿色表示本轮结束或就绪，灰色表示未知、过期或刷新失败。颜色由终端标题和输出推测，不是实时推送；手动刷新可获取新快照。

## tmux Doctor

保存验证完成后可以运行 Doctor，也可随时从服务器的三个点菜单重新运行。报告列出 SSH、tmux 版本、会话访问、鼠标与历史等检查结果。

确认没有 tmux 时，新建 tmux 入口会暂时不可用，普通 SSH shell 仍可使用。修改服务器配置或重新检查后会重新判断；“不可用”的限制记录在 5 分钟后过期，届时可再次检查。

首次使用 tmux 且满足初始化条件时，Doctor 提供配置预览、历史行数和首次配置确认，再创建最小配置。已有配置的服务器可查看报告并按需调整。创建条件、配置备份与撤销见 [Doctor 说明](testing/tmux-doctor.md)。

## 终端输入与滚动

点击终端或顶部键盘按钮后直接输入；中文组词确认后进入远端，回车由当前远端程序处理。

- 点亮 Ctrl、Shift、Alt 后再输入字符，可组合多个修饰键；下一次按键后释放。
- 底部快捷键栏可循环翻页，提供常用键、方向键和功能键。
- 快捷回复会进入编辑卡片；已有草稿时可选择追加或替换。
- 顶部编辑按钮或“工具 → 编辑文本”可编辑长文本，“插入终端”写入当前目标，不自动回车。
- “工具 → 选择复制”打开已加载文字的副本，可拖动系统选区复制；更早的内容先在终端滚动加载。

开启远端触摸后，上下滑动发送滚轮，轻点对应左键，长按后松开对应右键。滚动速度可设为 1×～10×；倍数增加滚轮事件，实际行数由 tmux 或远端程序决定。普通 shell 未开启鼠标时浏览手机本地历史。

tmux attach 会与电脑共享显示焦点和尺寸。回复目标变化、正在阅读历史或开启同步输入时，应用可能拒绝输入并保留草稿；核对当前 pane 后再操作。键盘、鼠标和目标行为的细节见 [终端输入](testing/terminal-direct-input.md) 与 [键盘验证](testing/terminal-keyboard.md)。

## 语音输入

voice 版首次使用需授予麦克风权限。按住语音按钮，准备完成并出现录音光晕后开始说话；剩余时长显示在录音提示中，接近上限时颜色改变。

松手后转写，上滑可取消；一次录音最长 60 秒。转写结果可在编辑卡片检查、修改或追加，再插入终端。识别支持中文、英文及中英混说，并生成标点和大小写。

## 文档与图片预览

点击终端中的 Markdown、HTML 或图片路径打开预览，例如 `docs/readme.md`、`/home/me/project/report.html`、`images/result.svg`。外部网页链接交给系统浏览器。

路径不正确时，在预览顶部修改完整文件路径并重试。相对路径以当前 pane 目录或登录目录为候选；绝对路径适合明确指定其他目录的文件。文档中的相对和绝对图片路径也可加载，PNG、JPEG、WebP、SVG 支持浏览，图片可缩放与拖动。

文档正文完整读取，内嵌图片优先加载当前可见区域及上下相邻区域。快速滑动时暂停过时下载，停稳后从新的位置继续；已下载图片可从本次预览缓存复用。

在“设置 → 文件预览”可以调整单文件和缓存上限，默认分别为 10 MiB、50 MiB；缓存不能小于单文件上限，修改在下次打开预览时生效。SVG 与其他图片使用相同单文件上限。HTML 为静态预览，详细范围见 [隐私与安全说明](privacy-and-security.md)。

## 连接保留与问题反馈

“设置 → SSH 连接保留”的无、少、中等、多、很多分别保留 0、1、2、3、5 条空闲 SSH 链，默认中等。保留期限为一分钟，退到后台关闭空闲链；正在使用的连接另计。空闲链不额外轮询任务状态。

回到首页后可重新进入会话；断线时可使用重连。tmux 会话的存活取决于服务器配置，普通 shell 与 tmux 的行为不同。

反馈问题时提供应用版本、手机与 Android 版本、复现步骤、预期和实际表现。复现后从“设置 → 调试日志 → 生成日志”导出，附上大致发生时间。日志在生成时截取快照，后续操作需重新导出。日志字段与采集方法见 [连接性能说明](testing/connection-performance.md)。
