# 0.6.4-dev：私钥粘贴与轻量日志

认证区改为私钥就绪状态、等宽文件/粘贴入口、独立口令输入。目标与跳板复用同一组件。粘贴弹窗默认遮蔽内容，仅主动点击才读取剪切板，允许长按粘贴、临时显示、取消与导入；不使用可恢复状态保存私钥草稿。支持 OpenSSH/PEM 文本封装、CRLF 归一化、64 KiB 上限。加密和实际认证路径沿用原实现。

设置删除任务状态灯解释，保留 README 使用说明作为 Wiki 基础。新增日志生成/清空入口；生成后交给系统文档保存器，不上传，不额外保存内部导出副本。

## 日志范围与资源预算

Application 启动时初始化，单后台工作线程异步写入。只开放枚举事件、数字字段与经处理的错误接口，不接收任意事件正文。记录前后台、SSH 阶段/成败、刷新批次、WebView 初始化/错误、行列/可见高度、首次渲染/断开时累计字节、输入保护失败、私钥导入方式。异常只写类别、固定原因与最多五层调用位置，不写异常原文或远端输出。

内部文件 `files/diagnostics/current.log` 和 `previous.log` 各不超过 128 KiB，满后轮转；队列最多 128 条，溢出丢弃并计数，日志 I/O 失败不阻断主功能。导出快照最多约 256 KiB 加固定头部，包含应用/Android/WebView 版本、当前进程启动时间与丢弃计数。保留两段跨进程日志；长时间使用会覆盖早期事件。手动清空后继续记录。用户导出的外部文件由用户管理。

枚举字段约定：REFRESH 系列 `a` 为配置 UUID 的 hashCode（不由主机/用户名产生），`b` 为自动标记或任务数量；CONNECT/CONNECTED/DISCONNECT 的 `a` 为本次连接代次，CONNECT 的 `b` 为跳板数量；SSH_STAGE 的 `b` 为跳板编号×10＋阶段码（准备 1、验证 2、已连接 3、其他 0）；WEB_READY/WEB_RESIZE 为列/行，VIEWPORT 为可见高度；OUTPUT_SUMMARY 的 `b` 为累计渲染字节。无别名、IP、域名、用户名、密钥、口令、剪切板、命令、终端正文。

Java/Kotlin 未捕获异常尽力同步写入一条并交回原异常处理器。系统杀进程、原生崩溃、断电/存储失败不保证最后记录。导出期间的快照仅存在于内存；若进程在系统保存界面被杀，需要重新生成。

## 验证覆盖

- 核心：轮转容量、重新打开仍能读取、清空、换行规范；私钥封装、公钥拒绝、CRLF、超长限制。
- Android：剪切板真实导入、非法公钥提示、取消保留原值、凭据保存、系统文件保存器真实导出、导出成功反馈、清空；带敏感标记的错误/阶段文本不进入日志。
- 整体回归：SSH/跳板、断线与输入保护、终端布局/键盘/触控、主题/设置、服务器组织与刷新、状态灯。

没有改动 Web JS 资产，本轮不重复桌面浏览器测试。剪切板和导出截图/文件来自临时测试数据，不含用户私钥。
